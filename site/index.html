Install Guide GitHub

Share your whole addon setup with one link

wowam is a free addon manager for World of Warcraft on Linux, Windows and macOS. It finds your installs, keeps your addons up to date and lets a guild or raid team stay on the same ones. Retail, Classic and Forever.

Download for Windows Download for macOS Install on Linux

No ads, no account, no tracking. MIT license.

Install somebody's setup in one click

Shared setups are listed in Browse. Open one to see what is in it, then install the lot. Or paste a link a friend sent you into the search box.

Follow a setup and the app tells you when its author adds or drops an addon.

Share yours

Click Share mine, give the setup a name and pick the addons. The app copies a link for you to pass around. Share again later and the same link is updated.

A setup is just a text file, so you can also write one by hand:

# name: Raid basics
# by: yourname
# for: Retail
# about: boss mods and a damage meter
gh:BigWigsMods/BigWigs
https://github.com/WeakAuras/WeakAuras2
wowi:12345

Updates that leave your settings alone

The app only changes the AddOns folder, and it backs up your settings before it updates anything. Pin an addon to a version, read the changelog, or go back to the previous one.

It can update in the background, sit in the tray and keep your WeakAuras from wago.io current too.

Everything it does

  • Finds your WoW installs on its own, also under Lutris, Steam and Wine
  • Installs and updates addons from GitHub, WoWInterface and Tukui with no account or key
  • Shows an addon's description and screenshots before you install it
  • Installs a downloaded zip when you drop it onto the window
  • Imports a whole interface pack, addons and their settings, onto your own character
  • Copies your interface from one character to another
  • Profiles to switch between sets of addons, for example raid and levelling
  • Shows which addon the game reported errors for
  • Wago Addons and CurseForge when you add your own key
  • Updates itself

Install

Windows

Download wowam-setup.exe and run it. Windows may warn that the installer is not signed. Choose "More info" and then "Run anyway".

Linux

Run this in a terminal:

curl -fsSL https://raw.githubusercontent.com/BilboTheGreedy/wowam/main/install.sh | sh

macOS

Download wowam-macos.zip, unzip it and move the app to Applications. The first time, right click it and choose Open.

Older versions are on the releases page.

Questions

Where do the addons come from?
GitHub, WoWInterface and Tukui work out of the box. Wago Addons and CurseForge work when you add your own key in Settings.
Does it touch my settings?
It only changes the AddOns folder. Before an update it makes a backup of the WTF folder, where the game keeps your settings.
An addon I want is only on CurseForge.
Download the zip in your browser and drop it onto the window. If the author also has it on GitHub, paste that link into Browse instead and it will get updates.
Something is broken.
Open an issue on GitHub.
